# AI Usage Declaration

Per the SonicSentinel AI SRS (Competition Integrity, item 10), all AI tools used
during development are declared here.

## Tools Used

- **Kiro (AI coding assistant)** — used to help scaffold and write the Python
  machine-learning pipeline: data organisation, audio preprocessing, feature
  extraction, and model-training scripts, plus documentation.

## How AI Was Used

- Generating and refactoring Python code for the ML pipeline modules.
- Building the Flask backend (database, auth, upload/validation, dual-model
  inference service, configurable alert engine) and wiring the existing UI to it.
- Structuring the project according to the SRS deliverables.
- Writing configuration, tests, documentation, and this file.
- Analysing the raw dataset (file inventory, duplicate detection, ESC-50 label mapping).

## What AI Was NOT Used For

- The final sound classification is produced by the trained Python model only.
  It is **not** generated by any external generative-AI API (per SRS item 12).
- No hard-coded predictions, invented confidence values, or hidden decision APIs
  are used (per SRS item 7).
- All labels reflect the real content of the data; no class was fabricated or
  mislabelled to fill a gap.

## Human Understanding

Every module in this repository is understood by the team and can be explained on
request, including preprocessing steps, extracted features, model choices, and
evaluation metrics (per SRS items 1, 4, and 11).
